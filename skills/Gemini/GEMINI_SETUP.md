# Setup di Google Gemini CLI, Gemini Skills, dan Gemini Gems

- **Gemini CLI Extension (3-in-1):** Gunakan `00-complete.zip` (`gemini-extension.json` + `skills/*/SKILL.md`).
- **Gemini Upload Keahlian (Skills Web):** Unggah `01-flow-storyboard-director.zip`, `02-realita-pov-scriptwriter.zip`, atau `03-faceless-documentary-script.zip` satu per satu (berisi 1 folder root `<skill-id>/SKILL.md` tanpa manifest plugin).
- **Gemini Gem Manual:** Tempel `GEM_INSTRUCTIONS.md` ke Instructions dan unggah file knowledge terpisah.
