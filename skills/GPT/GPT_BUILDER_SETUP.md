# Panduan Pemasangan di OpenAI ChatGPT / Custom GPT / Codex

### Cara Memasang di ChatGPT Custom GPT:
1. **Instruksi Asisten:**
   - Buka Custom GPT Editor (`chatgpt.com/gpts/editor`).
   - Masuk ke tab **Configure**.
   - Salin isi `SKILL.md` dari skill yang Anda inginkan (misal dari arsip `01-flow-storyboard-director-v*.zip`) ke kolom **Instructions**.
2. **Unggah Basis Pengetahuan (Knowledge):**
   - Di bagian **Knowledge**, unggah file referensi dari folder `references/` (misal: `katalog_48_gaya_visual.json`, `character-mode.md`, `cover-engine.md`).
3. **Simpan / Publikasikan:**
   - Klik **Create** / **Update** di sudut kanan atas.
